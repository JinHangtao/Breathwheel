## About

You stand at the center of a vast mandala sphere. Threads of metallic light drift and spiral into a glowing throat at its heart.

No images, no audio files — every frame and every sound is generated live. No two moments are the same.

## Controls

| Input | Effect |
|---|---|
| Mouse | The light follows you; the view shifts with parallax |
| Drag / tilt | Look around (gyroscope on mobile) |
| Scroll | Move through space, with depth-of-field blur |
| Click | Reveal controls; toggle Gold / Jade (`Space`) |
| Hold (or `B`) | Inhale — release to exhale |
| `V` / mic | Voice drives the visuals: sound exhales, silence inhales |
| Audio file | Your music shapes the visuals |
| `M` mute · `G` gyro off · `E` random event | |

## Features

- **Spherical space** — look in any direction from the center
- **Vortex horizon** — a gravitational throat spirals threads inward
- **Living breath** — an ~11-second cycle, each peak sending out a ring of light
- **Chance events** — ripples, fireflies, light curtains, heartbeats, prism shifts
- **Synthesized sound** — drones, bells and grain, with reverb and tape delay
- **Adaptive quality** — resolution drops automatically if the frame rate does
